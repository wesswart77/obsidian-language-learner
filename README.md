# Language Learner

Learn languages in Obsidian: vocabulary lists, grammar rules, example sentences, and progress tracking by level.

## Features

- **Vocabulary Notes** — Add words with translation, part of speech, CEFR level, example sentence, and notes
- **Grammar Rules** — Document grammar rules with explanations and examples
- **Vocabulary Quiz** — Interactive quiz that shows 10 random words and tracks known vs learning
- **Progress Sidebar** — Per-language stats: total words, breakdown by CEFR level (A1–C2), total grammar rules

## Usage

### Commands
- `Language Learner: New word` — Add a vocabulary word
- `Language Learner: New grammar rule` — Create a grammar rule note
- `Language Learner: Vocabulary quiz` — Start a vocabulary quiz session
- `Language Learner: Open progress` — Open the language progress sidebar

### CEFR Levels
Words are tagged A1, A2, B1, B2, C1, or C2 following the Common European Framework of Reference.

### Settings
- **Vocabulary folder** — Where word notes are saved (default: `Languages/Vocabulary`)
- **Grammar folder** — Where grammar rule notes are saved (default: `Languages/Grammar`)
